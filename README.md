# slack-post

Slack API を使って、ターミナルで入力したメッセージを、決めておいたチャンネルに投稿する Python プログラムです。

## 何をするものか

1. `.env` に書いた Bot トークンとチャンネル ID を読み込む
2. メッセージを入力する（複数行OK。空の行で入力終わり）
3. 投稿するメッセージを表示し、投稿してよいか確認する
4. Slack API の `chat.postMessage` でチャンネルに投稿し、投稿のリンクを表示する

```
% python main.py
投稿先のチャンネル：C0123456789
メッセージを入力してください（空の行で入力を終わります）
> こんにちは！
> Python から投稿しています。
>

--- 投稿するメッセージ ---
こんにちは！
Python から投稿しています。
--------------------------
投稿しますか？ (y/n): y
投稿しました。
https://xxxx.slack.com/archives/C0123456789/p1234567890123456
```

## 事前準備

### 1. ライブラリのインストール

```bash
pip install requests python-dotenv
```

### 2. Slack アプリの作成

1. [Slack API: Your Apps](https://api.slack.com/apps) で「Create New App」→「Blank app」（以前の画面では「From scratch」）→ アプリ名とワークスペースを選んで作る
2. 左のメニュー「OAuth & Permissions」→「Scopes」の **Bot Token Scopes** に `chat:write` を追加する
3. 同じページ上の「Install to ワークスペース名」→「許可する」
4. 表示された **Bot User OAuth Token**（`xoxb-` で始まる）をコピーする（下の `.env` に貼る）
5. Slack で投稿先のチャンネルを開き、`/invite @アプリ名` でボットを招待する
6. チャンネル名をクリック →「チャンネル詳細」の一番下にある **チャンネル ID**（`C` で始まる）をコピーする

スコープは投稿に必要な `chat:write` だけにしています。このスコープでは、ボットが参加しているチャンネルにしか投稿できないので、手順5の招待が必要です。

## 秘密ファイルの用意の仕方

トークンとチャンネル ID は GitHub に載せていません（`.gitignore` で除外）。自分で用意してください。

| ファイル | 中身 | 用意の仕方 |
|---|---|---|
| `.env` | Bot トークンと投稿先のチャンネル ID | `.env.example` をコピーして `.env` という名前にし、上でコピーした値を書く |

`.env` の例：

```
SLACK_BOT_TOKEN=xoxb-...（自分のトークン）
SLACK_CHANNEL_ID=C0123456789
```

## 使い方

```bash
python main.py
```

- メッセージは1行ずつ入力し、何も入力せずに Enter を押すと入力が終わります
- `y` で投稿、`n` で投稿をやめます
- `&` `<` `>` などの記号も、入力どおりに表示されます
- 投稿はボット（アプリ）の名前で表示されます
- 途中でやめたいときは Ctrl + C を押してください

## 安全のための工夫

- トークンはコードに書かず、GitHub に載せない `.env` に書きます
- スコープは `chat:write`（投稿）だけにしています。チャンネルを読むことはできません
- 投稿の前に、内容を表示して確認します

## うまくいかないとき

| 表示 | 対処 |
|---|---|
| 〜が設定されていません | `.env` を作り、`SLACK_BOT_TOKEN=` と `SLACK_CHANNEL_ID=` の後ろに値を書く |
| Bot トークンではありません | 「User OAuth Token」ではなく「Bot User OAuth Token」（`xoxb-`）をコピーする |
| Bot トークンが正しくありません | トークンを貼り直す。アプリを入れ直すとトークンが変わる |
| 投稿先のチャンネルが見つかりません | ボットをチャンネルに招待したか確かめる（招待していないチャンネルも「見つからない」になります）。チャンネル ID（チャンネル名ではなく `C` で始まる ID）を確かめる |
| ボットが投稿先のチャンネルに参加していません | チャンネルで `/invite @アプリ名` を送る |
| 投稿の許可（スコープ）がありません | Bot Token Scopes に `chat:write` を追加し、アプリを入れ直す |

詳しい仕様は [要件定義書.md](要件定義書.md) を見てください。
